# Unwinator

Unwinator is a browser extension that turns ordinary webpage text into a mixture of Stanley-Unwin-inspired word mangling and spoonerisms.

It works locally in the browser. It does not send webpage content anywhere.

## Install for development

1. Download or clone this repository.
2. Open `chrome://extensions` in Chrome or Edge.
3. Turn on **Developer mode**.
4. Choose **Load unpacked**.
5. Select this repository folder.
6. Pin Unwinator to the toolbar and adjust the Manglefactor.

Unwinator processes page text locally and stores only its own settings. It has no analytics, advertising, tracking or telemetry. See [`PRIVACY.md`](PRIVACY.md).
