# Unwinator

Turn ordinary web pages into stronger Unwinese-ish English, with extra spoonerisms.

Unwinator works entirely inside your browser. It does not send webpage content anywhere.

## Install it yourself in Chrome or Edge

1. Download the current source as a ZIP: https://github.com/antlerboy-benjamintaylor/unwinator/archive/refs/heads/main.zip
2. Unzip the download somewhere you can leave it permanently.
3. In Chrome, open `chrome://extensions`.
   In Edge, open `edge://extensions`.
4. Turn on **Developer mode**.
5. Click **Load unpacked**.
6. Select the unzipped `unwinator-main` folder — the folder containing `manifest.json`.
7. Pin **Unwinator** to the browser toolbar.
8. Open any normal webpage, click the Unwinator icon, switch it on and set the **Manglefactor**.

To update later, download the ZIP again, replace the old folder contents, then return to the extensions page and click the extension's **Reload** button.

## What it does

Unwinator changes visible webpage text locally in the page. It combines Stanley-Unwin-inspired word mangling with pairwise spooner-style sound swaps. It avoids form fields, scripts, code and similar elements.

## Privacy

Unwinator does not collect, transmit, sell, share or remotely store personal information, browsing history or webpage content. It stores only its own settings in Chrome's extension storage.
